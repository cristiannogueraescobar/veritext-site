# veritext-site

The public privacy policy for the VeriText browser extension.

This repository exists **only** to publish that page. The extension's source
lives in a separate private repository — GitHub Pages does not serve from a
private repo on the free plan, so the page needs a public home of its own.

Nothing here is part of the extension.
